# Portfolio Website - Sharanya N

A fully responsive, premium SaaS-inspired portfolio website built with modern HTML5, CSS3, and Vanilla JavaScript. Features glassmorphism, dynamic canvas particle networks, theme switching, and seamless client customization.

## Folder Structure
- `index.html`: Main entry point containing semantic markup and ARIA labels.
- `css/`: Modular stylesheet files (`style.css`, `animations.css`, `responsive.css`).
- `js/`: Application logic (`script.js`) and centralized data file (`data.js`).
- `assets/images/`: Place your project screenshots and profile picture here.
- `assets/resume/`: Place your PDF resume here.

## How to Update Your Information
To update text, projects, or links, simply edit **`js/data.js`**. You do not need to modify any HTML files.
